## 2. ブリリアントジャークとは（見極め対象の定義・当たり）

ブリリアントジャーク＝**高い能力（スキル・成果）を持つが、チームを蝕む人**。小野メソッドの4層に当てはめると特徴が分解できる：
- 地上1F/地下1F（スキル・成果志向）＝**高い**（だから採ってしまう）
- 地下2F ポテンシャル＝**共鳴力が欠落／胆力が「他者を踏む」方向に歪む**
- 地下3F 価値観＝**自己中心・チームの成功より自分の正しさ**

つまり見極めは「**能力軸が高いのに、共鳴力・価値観軸に特定の毒サインが出る"ねじれ"を検出する**」こと。単一スコアではなく**層をまたいだパターン**。

## 3. 技術的な当たり（小野メソッドと"同軸"の意味）

「同軸で」＝**LSRPのような別スコア機構を新設するのではなく、既存GUIDE構造の中に観察軸として織り込む**、が素直。3案：

- **案A（最小・推奨の当たり）**：既存`pote.共鳴力`・`values`の**obs（観察ポイント）にブリリアントジャーク特有の毒サインを追記**＋、Block1のAIプロンプトに「能力高・共鳴力低のねじれがあれば面接官に確認質問を出す」を追加。**新スコア・新ゲートを作らない＝法務リスク最小**。
- **案B（中）**：GUIDEに横断フラグ「協働性チェック」を1枚追加（設問4〜5・obsつき）。スコアは出すが**合否には使わず「面接官が事実確認する観点」**として表示（既存obsと同格）。
- **案C（大）**：ブリリアントジャーク専用の診断ブロック新設。**←LSRPと同型の法務負荷が発生。専務の法務レビュー必須。下調べ段階では非推奨。**

## 4. 法務制約の当てはめ（専務意見書・厳守）

- **LSRPの採用選考利用は避ける／スコア単独で合否を決めない** → ブリリアントジャーク見極めも**「弾く根拠」でなく「多面評価の一要素」**として実装。案A/Bはこの原則に合致（既存obsと同じ「面接官が事実確認する観点」）。案Cはスコア機構化するとLSRPと同じ同意ゲート・自動除外禁止の設計が要る。
- **柴山さんの実体験を素材に使う場合**：外部AIに送る前に**匿名化 or 本人同意**（要配慮個人情報）。→ 具体的な"えらい目に遭った"エピソードをAIプロンプトや設問例に埋め込むなら、匿名化必須。設問は一般化した行動質問に留めれば回避できる。
